# 線路設備 学習帳

電気通信主任技術者「線路設備及び設備管理」の学習用Webアプリ（スマホ対応・オフライン対応）。

- **ホーム**：試験日カウントダウン、試験日から逆算した学習プラン（チェックリスト）
- **要点**：7分野の要点まとめ
- **問題**：一問一答 151問（ランダム／未学習／苦手／全問）
- **計算**：数値が毎回変わる計算ドリル 15種類（稼働率、光損失バジェット、反射係数、Cp、クリティカルパスなど）
- **記録**：日別の解答数、分野別の正答率、バックアップ／復元

学習記録はブラウザ（localStorage）にだけ保存されます。

## GitHub Pages で公開する

1. GitHub でこのリポジトリを push する
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける
4. スマホでは Safari の共有 →「ホーム画面に追加」（Android Chrome はメニュー →「ホーム画面に追加」）でアプリのように使える

## 問題を追加する

`js/questions.js` の `QUESTIONS` に `{ id, cat, q, c: [選択肢...], a: 正解の番号(0始まり), e: 解説 }` を追加する。
